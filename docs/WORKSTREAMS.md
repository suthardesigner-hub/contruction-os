# Workstreams

1. Core: identity, membership, permissions, audit, magic links, repositories.
2. Field: morning target, evidence, evening result, missed reason, verification, escalation.
3. Procurement: requirement → PR → RFQ → quote → approval → PO → GRN → stock → issue → reconciliation.
4. Commercial: work order → measurement → certification → RA bill → eligibility → payment/ledger.
5. Quality/Client: drawings, RFI, QC, hold points, complaints, handover, warranty.
6. Automation/AI: event rules, Action Inbox, readiness, analytics, assistive AI.
7. Integration/QA: permissions, idempotency, audit/events, regression and contract compliance.
